## Sobre o projeto

Este portfólio foi criado inicialmente como uma forma de apresentar informações pessoais, interesses, conhecimentos e experiências acadêmicas.

Com o avanço dos meus estudos em **Engenharia de Software** e o desenvolvimento de novos projetos, o site passou por uma reformulação para representar melhor minha trajetória atual na área de tecnologia.

A versão atual do portfólio possui maior foco em:

- Projetos acadêmicos e práticos.

## Estrutura do site

O site está organizado em diferentes seções para facilitar a navegação e a apresentação das informações.

### Apresentação

A página inicial apresenta meu nome, minha área de formação e alguns dos principais temas com os quais venho trabalhando durante meus estudos.

Atualmente, o destaque está voltado para **Engenharia de Software, ServiceNow e desenvolvimento de aplicações**.

### Sobre mim

A seção apresenta um resumo da minha trajetória acadêmica e dos conhecimentos que venho desenvolvendo durante a graduação.

O objetivo é apresentar de forma breve minha evolução na área de tecnologia e meu interesse por desenvolvimento, sistemas e tecnologias corporativas.

### Projetos em destaque

O site possui uma área dedicada aos principais projetos desenvolvidos durante meus estudos.

Entre eles estão:

#### 🐾 AU FOOD

Aplicação desenvolvida no **ServiceNow App Engine Studio** para gerenciamento de uma loja fictícia de produtos para pets.

O projeto trabalha com:

- Cadastro e gerenciamento de produtos;
- Controle de estoque;
- Registro de pedidos;
- Relacionamentos entre tabelas;
- Importação de dados via Excel;
- Controle de acesso por funções;
- Categorias e subcategorias dependentes;
- Automação do processo de aprovação de pedidos utilizando o **Flow Designer**.

O projeto possui um repositório próprio no GitHub com documentação e capturas de tela da aplicação.

#### 🔐 Escape Room em C++

Projeto acadêmico desenvolvido utilizando **C++**, envolvendo lógica de programação e resolução de desafios em uma experiência inspirada em uma sala de fuga.

O projeto foi utilizado para colocar em prática conceitos estudados durante a graduação.

#### 🌐 Portfólio Web

O próprio site também faz parte dos meus projetos.

Ele foi desenvolvido utilizando **HTML e CSS** e vem sendo atualizado conforme avanço nos estudos e desenvolvo novos projetos.
